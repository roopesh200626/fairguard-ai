# 📄 Reports Directory

This directory stores all the automated compliance documents and fairness certificates generated by FairGuard AI.

## 🎯 What Gets Generated Here?

When an audit or debiasing run is completed in the application, users can export the results. The PDF files are saved here for record-keeping, compliance checks, and regulatory submissions.

## 📋 PDF Report Contents

The **Regulatory Compliance Report** provides a deep dive into the model's fairness profile:
- **Executive Summary**: High-level overview of the bias audit and model accuracy.
- **Metric Breakdown**: Detailed scores for Demographic Parity, Equal Opportunity, Predictive Parity, and Disparate Impact.
- **Intersectional Analysis**: Highlights the most vulnerable sub-groups.
- **Mitigation Results**: Comparison of the original model versus the debiased model.
- **Regulatory Checklist**: Line-by-line compliance status against 7 global regulations (EU AI Act, DPDP India, etc.).

## 🏅 Certificate Contents

The **AI Fairness Certificate** is a cryptographic, secure document awarded only if the model's bias score is well below the critical threshold (Bias < 0.10). It includes:
- The verified Model Name
- Final Audited Bias Score
- Protected Attributes Evaluated
- A secure issuance ID and timestamp for verifiable compliance.
